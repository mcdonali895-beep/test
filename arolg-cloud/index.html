02 — So funktioniert's

Von der Datei zum verteilten Bucket in drei Schritten.

01

Bucket anlegen

Region wählen, Zugriffsschlüssel erzeugen. Staging und Produktion sind sofort getrennt.

$ arolg bucket create backups --region fra1
02

Hochladen

Per S3-API, AWS-CLI oder rclone. Jeder Upload landet sofort verteilt und redundant.

$ aws s3 cp ./dump.tar s3://backups/
03

Verteilen

Mehr Kapazität, mehr Regionen, Replikation dazu – ohne Migration und ohne Downtime.

$ arolg bucket replicate backups --to nue1
